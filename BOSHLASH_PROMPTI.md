# AI bilan ishlashni boshlash

Claude Code yoki Codex'ni ochganda **birinchi xabar** sifatida quyidagini nusxalab yuboring:

```
Salom. Men dasturchi emasman, kodni tushunmayman. Bu loyiha qoidalari AGENTS.md faylida yozilgan, avval uni o'qib chiq va hamma qoidalarga amal qil.

Hozir:
1. Saytni ishga tushir (MySQL va php artisan serve --port=8000). Laragon yopiq bo'lsa ham o'zing yoqishga harakat qil.
2. Hozirgi holatni git commit qilib saqlab qo'y.
3. Tayyor bo'lgach, menga o'zbek tilida qisqa qilib ayt: sayt ishlayaptimi.
4. Saytni o'zing ochma (ichki brauzer yoki preview ishlatma). Men uni Chrome'da o'zim ochaman. Menga manzilni aynan http://127.0.0.1:8000/login deb ber: bir marta bosiladigan link qilib, bir marta nusxalash uchun alohida blokda.

Keyin men senga saytda nimani o'zgartirish kerakligini yozaman. Har bir o'zgarishdan keyin nima qilganingni va qaysi sahifada ko'rishim mumkinligini oddiy tilda tushuntir.
```

## Keyingi so'rovlar uchun namunalar

- `Bosh sahifadagi sarlavhani "..." ga o'zgartir`
- `Admin paneldagi chap menyuga yangi bo'lim qo'sh: ...`
- `Login sahifasining rangini ko'kdan yashilga o'zgartir`
- `Sayt ochilmayapti, tekshirib tuzat`
- `Oxirgi o'zgarish yoqmadi, orqaga qaytar`
- `Bugun nimalarni o'zgartirganimizni sanab ber`
